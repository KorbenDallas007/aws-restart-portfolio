## 🔧 Conceptos Clave

### IAM Components

- **Users**: Identidades individuales
- **Groups**: Colecciones de users
- **Roles**: Identidades assumibles
- **Policies**: Permisos detallados
- **MFA**: Autenticación de dos factores

### Security Best Practices

✅ Habilitar MFA para todos los users  
✅ Implementar least privilege  
✅ Usar roles en lugar de keys de acceso  
✅ Rotar credenciales regularmente  
✅ Habilitar CloudTrail para auditoría  
✅ Implementar encryption  
✅ Usar Security Hub para compliance
