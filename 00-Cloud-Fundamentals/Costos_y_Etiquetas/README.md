# Costos y Etiquetado 💰

Gestión eficiente de costos en AWS mediante etiquetado de recursos y optimización.

## 📋 Contenido

Este módulo cubre:

- **Etiquetado de recursos**: Tagging strategy
- **Administración de costos**: Cost allocation
- **Monitoreo de gastos**: Budget alerts y Cost Anomaly Detection
- **Optimización**: Identificar y reducir desperdicio
- **Reportes**: Cost analysis y forecasting

## 🎯 Laboratorios Incluidos

### Lab 188 - Administración de Recursos mediante Etiquetado
Implementar una estrategia completa de etiquetado para gestionar recursos.

### Lab 189 - Optimizar la Utilización
Análisis y optimización de costos identificando recursos subutilizados.

## 🏷️ Estrategia de Etiquetado

Ejemplo de tags recomendados:
- `Environment`: development, staging, production
- `Owner`: team o persona responsable
- `Project`: nombre del proyecto
- `CostCenter`: centro de costos
- `Application`: aplicación específica

## 💡 Mejores Prácticas

✅ Implementar tagging policy en la organización  
✅ Usar AWS Tagging Strategy  
✅ Monitorear costos regularmente  
✅ Configurar budgets y alertas  
✅ Revisar RI y Savings Plans  
✅ Eliminar recursos no utilizados
