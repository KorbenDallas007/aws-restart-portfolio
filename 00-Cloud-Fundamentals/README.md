# Cloud Fundamentals 🌥️

Fundamentos esenciales de AWS Cloud Computing, incluyendo automatización, CLI, infraestructura como código y gestión de costos.

## 📁 Estructura de Carpetas

### [Automatizacion_SSM](./Automatizacion_SSM/)
Laboratorios sobre **AWS Systems Manager** para automatización de infraestructura y gestión centralizada de recursos.
- Automatización de tareas administrativas
- Gestión de configuraciones
- Ejecución remota de comandos

### [CLI_y_SysOps](./CLI_y_SysOps/)
Guías prácticas para **AWS CLI** y operaciones del sistema.
- Instalación y configuración de AWS CLI
- Operaciones CLI avanzadas
- Automatización con scripts

### [CloudFormation](./CloudFormation/)
Introducción a **Infrastructure as Code** usando AWS CloudFormation.
- Templates YAML/JSON
- Stacks y recursos
- Mejores prácticas

### [Costos_y_Etiquetas](./Costos_y_Etiquetas/)
Gestión de costos y etiquetado de recursos en AWS.
- Administración de recursos mediante etiquetas
- Optimización de costos
- Análisis de gastos

## 🎯 Objetivos de Aprendizaje

- Comprender los fundamentos de AWS Cloud
- Automatizar infraestructura con CloudFormation
- Usar AWS CLI para gestión de recursos
- Optimizar costos mediante etiquetado y monitoreo
