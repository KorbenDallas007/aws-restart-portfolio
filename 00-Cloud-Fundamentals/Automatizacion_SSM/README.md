# AWS Systems Manager - Automatización 🤖

Laboratorios prácticos sobre **AWS Systems Manager (SSM)** para automatización de infraestructura, gestión centralizada y operaciones en escala.

## 📋 Contenido

Este módulo cubre:

- **Automatización de tareas**: Scripts y runbooks automáticos
- **Parameter Store**: Almacenamiento seguro de configuraciones
- **Session Manager**: Acceso seguro a instancias EC2
- **Maintenance Windows**: Programación de mantenimiento
- **Patch Manager**: Gestión automática de parches

## 🎯 Laboratorios Incluidos

### Lab 169 - Uso de AWS Systems Manager
Introducción completa a AWS Systems Manager con ejercicios prácticos.

## 🚀 Cómo Usar Estos Laboratorios

1. **Requisitos**: Cuenta AWS activa con permisos de SSM
2. **Acceso**: Revisa la documentación en los archivos markdown
3. **Práctica**: Ejecuta los pasos siguiendo las instrucciones
