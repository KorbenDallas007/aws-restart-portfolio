# AWS CloudFormation 🏗️

**Infrastructure as Code** con CloudFormation para automatizar el despliegue de infraestructura en AWS.

## 📋 Contenido

Este módulo cubre:

- **Conceptos IaC**: Infrastructure as Code principles
- **Templates**: YAML/JSON CloudFormation templates
- **Stacks**: Gestión de stacks y recursos
- **Parameters**: Parametrización de templates
- **Troubleshooting**: Diagnóstico y resolución de problemas

## 🎯 Laboratorios Incluidos

### Lab 190 - Automatización de Implementaciones con CloudFormation
Implementar infraestructura completa usando CloudFormation templates.

### Lab 191 - Actividad de Café: Resolución de Problemas
Scenario-based troubleshooting de deployments CloudFormation.

### Lab 192 - Desafío CloudFormation
Caso de uso avanzado para aplicar todos los conceptos aprendidos.

## 🔧 Recursos Incluidos

- **challenge.yaml**: Template con desafío
- **task1.yaml**: Template de ejemplo para comenzar
- **images/**: Capturas de pantalla del laboratorio

- Stack Creation & Management
- Parameters & Outputs

- Resources & Properties
- Error Handling
