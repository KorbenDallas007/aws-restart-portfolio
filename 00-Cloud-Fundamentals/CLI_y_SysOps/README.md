# AWS CLI y SysOps 💻

Guías prácticas para dominar **AWS Command Line Interface (CLI)** y operaciones del sistema.

## 📋 Contenido

Este módulo cubre:

- **Instalación y configuración**: Setup de AWS CLI
- **Credenciales**: Manejo seguro de acceso (IAM credentials)
- **Configuración regional**: Selección de regiones y perfiles
- **Operaciones básicas**: Comandos esenciales de AWS
- **Scripting**: Automatización con CLI

## 🎯 Laboratorios Incluidos

### Lab 168 - Instalar y Configurar AWS CLI
Guía paso a paso para instalar y configurar AWS CLI en tu entorno.

## 🛠️ Temas Principales

- Instalación en Windows/Linux/macOS
- Configuración de credenciales
- Perfiles y roles
- Salida de comandos (JSON, tabla, texto)
- Configuración de region por defecto

## 💡 Mejores Prácticas

✅ Usar variables de entorno para credenciales  
✅ Crear perfiles separados por entorno  
✅ Usar IAM roles en lugar de claves de acceso cuando sea posible  
✅ Documentar comandos frecuentes en scripts  
✅ Validar permisos antes de ejecutar operaciones
