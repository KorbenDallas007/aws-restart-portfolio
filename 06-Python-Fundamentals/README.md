## 🐍 Conceptos Clave

### Tipos de Datos
- `str`: Strings
- `int`, `float`: Números
- `list`, `tuple`: Secuencias
- `dict`: Diccionarios
- `set`: Conjuntos

### Control de Flujo
- `if/elif/else`: Condicionales
- `for/while`: Loops
- `break/continue`: Control
- `try/except`: Manejo de excepciones

### Funciones
```python
def saludar(nombre):
    """Docstring de función"""
    return f"Hola, {nombre}!"
```

### Estructuras de Datos

#### Listas
```python
lista = [1, 2, 3, 4, 5]
lista.append(6)
lista.pop()
```

#### Diccionarios
```python
usuario = {
    "nombre": "Juan",
    "edad": 30,
    "ciudad": "Madrid"
}
```

#### Tuples
```python
coordenadas = (10, 20)  # Inmutable
```
