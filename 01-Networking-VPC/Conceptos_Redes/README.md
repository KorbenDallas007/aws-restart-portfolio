# Conceptos de Redes 🌐

Fundamentos de networking, direcciones IP, subredes y solución de problemas de red en AWS.

## 📋 Contenido

Este módulo cubre:

- **Direcciones IP**: Públicas, privadas, elásticas
- **Subredes**: CIDR, creación y gestión
- **Routing**: Tablas de ruta y gateways
- **Seguridad**: Security groups y NACLs
- **Diagnóstico**: Herramientas de troubleshooting

## 🎯 Laboratorios Incluidos

Diferenciación y asignación de direcciones públicas y privadas.

### Lab 262 - Direcciones IP Estáticas y Dinámicas
Elastic IPs vs direcciones dinámicas.

### Lab 263 - Crear Subredes en una VPC
Diseño y creación de subredes.

### Lab 264 - Recursos de Red para una VPC
Gateway, NAT, VPN endpoints.

### Lab 265 - Comandos de Solución de Problemas del Protocolo de Internet
Herramientas de diagnóstico: ping, traceroute, netstat, etc.

### Lab 266 - Solución de Problemas de una Red
Troubleshooting práctico de conectividad.

### Lab 267 - Creación de una VPC y Lanzamiento de un Servidor Web
Proyecto integrador: crear VPC completa con instancia web.

## 🔧 Conceptos Clave

- **CIDR Notation**: 10.0.0.0/16
- **IP Ranges**: IPv4 e IPv6
- **Subnetting**: División lógica de redes
- **Network ACLs**: Stateless firewall
- **Security Groups**: Stateful firewall
