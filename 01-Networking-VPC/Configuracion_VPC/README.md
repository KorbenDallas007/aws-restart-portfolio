# Configuración de VPC ⚙️

Configuración práctica y avanzada de Virtual Private Cloud (VPC) en AWS.

## 📋 Contenido

Este módulo cubre:

- **VPC Setup**: Creación y configuración de VPCs
- **Subnets**: Públicas y privadas
- **Routing**: Tablas de rutas y gateways
- **NAT**: Network Address Translation
- **Peering**: Conexión entre VPCs
- **Troubleshooting**: Diagnóstico de problemas

## 🎯 Laboratorios Incluidos

### Lab 180 - Configuración de Amazon VPC (JAWS)
Guía completa de configuración de VPC desde cero.

### Lab 181 - Actividad: Troubleshoot de una VPC (JAWS)
Scenario-based troubleshooting de conectividad y configuración.

## 🔧 Temas Principales

1. **VPC Creation**
   - CIDR blocks
   - DNS hostnames
   - DNS resolution

2. **Subnets**
   - Availability Zones
   - Public vs Private
   - Route table association

3. **Internet Gateway**
   - Attach to VPC
   - Route configuration

4. **NAT Gateway**
   - Elastic IP
   - Private subnet outbound access

5. **Network ACLs**
   - Inbound/Outbound rules
   - Stateless behavior

## 💡 Mejores Prácticas

✅ Documentar CIDR ranges  
✅ Usar multiple Availability Zones  
✅ Separar subnets públicas y privadas  
✅ Implementar layered security  
✅ Monitorear flujo de tráfico
