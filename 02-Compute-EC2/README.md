# Compute - EC2 🖥️

Amazon EC2 (Elastic Compute Cloud) es el servicio fundamental de computación en AWS. Este módulo cubre desde conceptos básicos hasta escalado y balanceo de carga.

## 📁 Estructura de Carpetas

### [Escalado_y_Balanceo](./Escalado_y_Balanceo/)
Configuración de Auto Scaling y Load Balancing para alta disponibilidad.
- Auto Scaling Groups
- Load Balancers (ELB, ALB, NLB)
- Route 53 Failover

### [Fundamentos_Linux_y_EC2](./Fundamentos_Linux_y_EC2/)
Conceptos básicos de EC2 y administración de Linux en instancias.
- Introducción a EC2
- Linux fundamentals
- AMIs y seguridad

### [Serverless_y_Contenedores](./Serverless_y_Contenedores/)
Alternativas a EC2: Lambda, ECS, EKS, Fargate.
- AWS Lambda
- Containers con ECS/EKS
- Fargate

### [Servidores](./Servidores/)
Configuración y gestión avanzada de instancias EC2.
- Instance types y sizing
- Storage optimization
- Performance tuning

## 🎯 Objetivos de Aprendizaje

- Lanzar y configurar instancias EC2
- Comprender Linux fundamentals
- Implementar escalado automático
- Distribuir tráfico con load balancers
- Explorar alternativas serverless

## 🔧 Temas Principales

- Instance types (t2, t3, m5, c5, etc.)
- AMIs y snapshots
- EBS volumes
- Security groups
- IAM roles
- Auto Scaling
- Load Balancers
